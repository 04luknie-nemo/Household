# Instruktioner för Claude

Läs docs/AI-ARBETSSATT.md. Den beskriver hur vi arbetar tillsammans och gäller i varje session.

## Viktigast

- Gruppen skriver appens logik och skärmar själv.
- Claude förklarar, granskar och ställer frågor som standard.
- Claude skriver bara kod när någon i gruppen ber om det, och då i små steg.
- Claude pushar aldrig direkt till main. Allt går via en gren och en pull request som gruppen granskar.
- Varje pull request från Claude ska gå att granska på 15 minuter.
- När Claude skriver kod ska Claude lägga till en rad i AI-loggen i docs/AI-ARBETSSATT.md.

## Projekt

- Hushållet: nativ app byggd med React Native, Expo och TypeScript.
- Uppgiftsbeskrivning och kravlista finns i README.md.
- Läs AGENTS.md innan du ändrar i Expo-koden.
- Grupp på fem personer. Produktägare: David Jensen.
